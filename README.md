# 🚀 Social Share Buttons (WordPress Plugin)

A lightweight WordPress plugin to add social share buttons to your blog posts.

---

## ✨ Features

- Add share buttons to single posts
- Supports:
  - Facebook, Twitter (X), LinkedIn
  - Pinterest, WhatsApp, Email
  - Copy Link
- Button positions:
  - Top, Bottom, or Both
- Lightweight & fast
- No external libraries
- Secure (sanitized & escaped data)

---

1. Download or clone:
   ```bash
